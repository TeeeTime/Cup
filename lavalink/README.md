# Lavalink Setup

> Lavalink is the application that handles audio playback for 
> the discord bot audio streaming capabilities.

![Required Version](https://img.shields.io/badge/Required_Jar-4.2.2-blue)

## Installation

1. **Download the file**  
   Grab the required `.jar` from the [releases page](https://github.com/lavalink-devs/Lavalink/releases). Make sure to download the correct version.


2. **Place it in this directory**  
   Move the downloaded `.jar` directly into this folder (it should sit right next to this `README.md`, the `start.bat` and the `application.yml` file).


3. **Check file name**  
   Make sure the file name is `Lavalink.jar`.


4. **Run the batch script**  
   Double-click the batch file or run it from your terminal to launch the `.jar`:
   ```cmd
   .\start.bat
   ```
